## 原始 API 快照不属于使用指南

`spec/pages/**/*.md` 是文档站同步的原始接口快照，也是生成器与测试的输入。它们可能保留上游旧字段、示例或已知缺陷；不因项目更名或文档整理批量改写。当前 MCP 约束由 `spec/overrides.yaml` 修正并生成 `spec/tools.json`，详情见 [spec 说明](../spec/README.md)。

Session 的维护源是 `spec/dynamic-proxy-session.md`，Skill 内副本由 `build-skills` 生成；不要将生成副本作为另一份手工维护文档。
