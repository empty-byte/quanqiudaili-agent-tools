## 二、待手动联调（需要测试账号 token）

配置方式见 README，默认模式就是全部工具，装一次即可。用 Inspector 手动点工具最方便，token 必须通过 `-e` 传入，终端里设的环境变量传不进子进程：

```
npx @modelcontextprotocol/inspector -e QQDL_TOKEN=你的token -- node <安装目录>/dist/src/index.js
```
