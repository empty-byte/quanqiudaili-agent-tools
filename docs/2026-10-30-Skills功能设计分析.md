# 全球代理 Skills 功能设计分析（历史方案）

> 状态：2026-10-30 实施前的设计记录，已由当日实现替代。本文件不再作为安装或开发待办。当前使用见 [使用指南](../USAGE.md)，实现及验证边界见 [需求与实施记录](2026-10-30-需求与实施记录.md)，文档分类见 [阅读入口](README.md)。

## 原始需求与保留的决定

项目从仅提供 MCP 的定位扩展为 `quanqiudaili-agent-tools`。用户选择让 Skills 依赖现有 MCP，补充面向全球代理使用者的业务流程；不在 PHP 后端另加 Skills 服务，不另写绕过 MCP 的 HTTP 客户端。

分析依据是本仓库与 `proxy-distribution-system` 的当时本地源码，以及 Agent Skills 文档。分析阶段没有调用线上接口、安装客户端或验证线上后端部署版本。

保留的分工已落实：

- `skills/quanqiudaili/SKILL.md` 负责识别产品、路由流程、核对目标和解释结果，按需加载参考文件。
- MCP 负责工具注册、参数校验、写确认和请求编码；后端继续负责鉴权、计价与执行。
- 续费沿用当前账号设置、搜索结果逐项核对、用户拒绝即停止、写结果未知不自动重试，继续由代码保护和流程指导共同处理。
- Session 规范保持单一来源，MCP 资源不可用时读取 Skill 内生成副本。切换会话不等于创建业务子账号。

## 结论的有效范围

当前完成的是本地源码实现及当日实施记录所列的离线验证，不代表每家客户端 GUI、真实业务写操作或线上后端版本都已验收。仓库更名也不证明实现已提交、推送或发布；发布状态应独立核对。

规则维护位置：业务流程在 [Skill](../skills/quanqiudaili/SKILL.md)，工具修正在 [overrides](../spec/overrides.yaml)，原始接口快照与生成关系见 [spec 说明](../spec/README.md)。不要用本历史分析覆盖当前工具 schema。

当时查阅的规范：[Agent Skills](https://agentskills.io/specification)、[OpenAI Skills 说明](https://developers.openai.com/plugins/concepts/skills)、[Claude Code Skills](https://code.claude.com/docs/en/skills)。这些链接保留为设计来源，不表示本轮重新验证了第三方客户端的最新行为。
