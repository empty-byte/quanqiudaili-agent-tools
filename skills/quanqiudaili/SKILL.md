# 全球代理操作

把用户的业务要求转换为已安装的全球代理 MCP 工具调用。工具负责参数校验、HTTP 请求和写操作确认；本技能负责选择产品、查清目标与价格、组织步骤和解释结果。

## 开始操作

1. 在客户端可用工具中查找本技能使用的逻辑名称。不同客户端可能加服务器或插件前缀，使用实际暴露的工具名，不硬编码前缀。
2. 找不到工具时，说明需要安装或启用全球代理 MCP；只有只读工具时，只完成查询并说明当前连接为只读。不要改成直接 HTTP 请求、关闭确认或替用户启动另一个写连接。
3. API Key 由客户端配置中的 `QQDL_TOKEN` 提供；本技能不需要读取它。认证失败时指导用户在网站 API Keys 页面核对并更新配置，不索取、复述或保存密钥。
4. 只加载本次工作对应的参考文档：

| 用户要做的事 | 读取内容 |
|---|---|
| 了解产品、查库存与价格、购买流量或 IP、申请测试 IP。 | [产品与购买](references/products-and-purchase.md)。 |
| 查找或创建子账号、改备注或账密、开关直连、查用量及设限流。 | [账号与流量](references/accounts-and-traffic.md)。 |
| 普通续费、产品 11 续费、带宽试算和升级、监控带宽。 | [续费与带宽](references/renew-and-bandwidth.md)。 |
| 删除动态账号、提交静态或产品 11 退单申请。 | [删除与退单](references/delete-and-refund.md)。 |
| 获取连接信息、指定动态出口地区、生成轮换或粘性会话连接串。 | [代理连接](references/proxy-connections.md)。 |

[工具归属表](references/tool-map.json)列出全部工具及所属流程，供维护和覆盖检查；不要为一次普通请求读取全部参考文档。

## 所有流程共用的判断

- 产品 1/6 是按 GB 计费的动态住宅流量；2/3/4/8 是按 IP 和时长计费；11 是按带宽计费的动态住宅不限流量。先确认业务含义，不凭“动态”“住宅”一个词猜产品。
- 以当前工具的输入 schema 为可调用边界。参数不被支持时，不换一个相似字段尝试绕过，也不以其他产品的报价代替。发现参考文档与实际工具不符时报告差异。
- 除订单 ID 等工具明确要求的整数外，子账号 ID 按字符串传。产品 11 的列表 `id`、本地 `sub_account_id` 和首购 `order_product_buy_id` 是三种不同标识。
- 在修改、续费、升级、删除或退单前，用 `sub_account_list` 找到目标，核对产品、账号名、ID、订单及当前状态。用户明确提供 ID 时按 ID 查；搜索结果不能直接视为已经匹配。
- `searchArr` 在旧产品上零命中可能返回全部账号；逐条核对所请求的用户名或 IP，备注搜索还需确认业务范围。返回全量、多个候选、缺失目标或分页未完整时，不执行批量写操作。
- `page` 从 1 开始，`pagesize` 不超过 100。需要“全部”或统计总数时按响应分页，不能把当前页当全量；只操作本次明确选中的 ID。
- 价格、库存与可操作状态以当次查询为依据。报价不是锁价，库存查询不是预留。只查余额时优先 `user_balance`，它的 `data` 是元金额字符串。
- 密码仅在用户要求交付或修改连接凭据时使用；汇总与排障输出默认遮蔽，不把凭据写入公开文件、命令历史或无关日志。

## 写操作确认与结果

每个写工具都经过现有 MCP 确认层，包括不扣费的创建账号和修改备注。先明确目标、参数、费用或影响；不把“查询”“试算”“生成连接串”扩展成创建、扣款或删除。

支持弹窗时，由 MCP 展示最终预览；未确认或不支持弹窗时，向用户转述返回的预览与重要影响，等待明确同意。仅在用户同意后，以相同业务参数携带本次 `confirm_token` 调用。用户拒绝、取消或未回复时停止。不要自己使用 `--yes`，不要为绕过静默期反复调用；确认码失效或业务参数变化时重新获取预览。一次同意不能复用到另一笔写操作。

工具成功返回的 `code/msg/data` 是执行结果；`isError` 为真时不得报告成功。只输出已经得到证据的状态：

- 查询失败或参数校验失败：解释具体原因，补齐信息后再继续。
- 写请求超时、连接中断或异常导致结果未知：停止后续写操作，不自动重下单、续费或退款。查询能够核对的目标状态；仍不能确定时请用户在网站订单记录核实或联系支持。余额变化、某一页没出现账号均不足以证明失败。
- 批量操作部分成功：列出已确认成功、失败和未知的项目，未获确认不要重做整批。
- 退单成功仅表示申请已提交，审核与到账需另行确认。
- 限流或临时故障：只读查询可按服务提示稍后重试；写操作先判断是否已经执行，禁止无界重试。

完成后说明操作对象、实际结果、费用或有效期（仅限返回值可证实的内容）及仍待处理的事项。
