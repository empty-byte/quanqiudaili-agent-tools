# 续费与带宽

## 普通时长续费

`order_renew` 用于产品 2/3/4/8。先查 `sub_account_list` 核对 ID、产品、到期时间、自动续费开关与带宽续费设置；每批最多 300 个，ID 使用英文逗号连接，去空白和重复项。产品 8 不能续 7 天。

MCP 会在确认前读取并保留 `is_renew`，不要添加工具未暴露的 `is_renew` 参数。**本次续费时长会写成以后自动续费的时长**，应在确认前告知用户。`renew_with_bandwidth` 未传时沿用当前设置；显式传 0 会让续费段按 5 Mbps 计价，当前带宽周期结束后回落，并同时改变后续带宽续费设置。仅在用户明确要求改变时传值。

需保留的自动续费设置不同，按设置分别续费；不要为了凑一批而统一关闭。MCP 前置查询提示目标缺失、设置不一致或查询失败时，说明尚未续费，先解决目标或分组。确认码调用若因设置变化而不匹配，应重新展示最新预览，不能绕过保护。

当前 MCP **没有产品 2/3/4/8 按选定子账号精确试算续费总额的工具**。无参 `product_unit_price` 提供对应产品、国家、周期的 IP 价格，供续费估算；后端实际按国家和续费带宽分组计算，再应用该组数量、套餐、自定义价及额度等规则，不能把新购单价乘总账号数当成保证扣费。产品 11 的报价分支和 `bandwidth_upgrade_price` 都不能代替普通续费报价，MCP 确认预览也不会补算费用。

含带宽续费时，用 `bandwidth_detail` 核对当前生效的带宽段，并用 `bandwidth_package_list` 查询相应产品、国家和档位的价格，区分 IP 费与带宽附加费。后端续费取当前生效带宽，无有效带宽段按 5 Mbps；不要用未来带宽段或升级差价估算整段续费。套餐的 `price` 是每 IP 每天未乘档位折扣的价格，`month_price` 是 30 倍，不能直接当最终带宽费用。资料不足时列明已知价格和缺失项，不编造精确总额；用户要求精确金额或严格费用上限而现有数据无法满足时，停在报价阶段并说明需网站确认实际续费费用，不能先续费来探价。

## 产品 11 续费

`order_renew_dynamic_bandwidth` 使用本地 `sub_account_id`，不是列表的 Go `id`。先查列表及 `can_renew`，再用 `product_unit_price` 传产品 11、本地 ID 与 `bill_timelen` 试算，核对余额并确认。

续费沿用当前网关和带宽；未到期从原到期时间延长，已到期从当前时间起算，到期后 7 天内可续。赠送测试账号、有待审退单的账号不能续费；产品 11 无自动续费。周期 1/2/3 对应 30/90/180 天。

## 带宽试算与升级

| 产品 | 先查与试算 | 执行工具及约束 |
|---|---|---|
| 2/3/4/8 | `bandwidth_package_list` 按产品与国家查档位；`bandwidth_detail` 查有效期内已购各段带宽；`bandwidth_upgrade_price` 传 `sub_accounts` 数组、目标 Mbps、产品。 | `order_bandwidth_upgrade` 使用 `subAccountIds` 数组，同一批 ID；所有账号须同国家、未到期，每次最多 300 个。实际支持档位与可升级性以后端为准。 |
| 11 | `sub_account_list` 查当前带宽及本地 ID；`bandwidth_upgrade_price` 传产品 11、`sub_account_id`、目标 Mbps。 | `order_upgrade_dynamic_bandwidth` 传相同本地 ID 与目标带宽，只升不降、立即生效、到期时间不变。 |

普通带宽试算会跳过不属本人或产品不符的 ID，也不完整验证同国家和批量上限，因此先核对账号范围，不能以有报价证明全部目标合法。目标档位要高于当前及已购未来段带宽；下单失败的笼统错误不能证明未扣款，遵守结果未知处理。

`bandwidth_package_list` 的 `price` 是每 IP 每天、尚未乘档位折扣的价格，`month_price` 为它的 30 倍，不等于整批最终价。产品 11 升级报价的 `realPrice` 是总差价，`list` 提供升级前后带宽、剩余天数和到期时间；它不支持优惠券。直接使用当次试算结果，不凭月价自行保证费用。两类升级均从余额扣费，经确认后才执行。

## 带宽监控

- `bandwidth_monitoring_list` 查询产品 2/3/4/8 的一批子账号，`subAccounts` 为字符串数组。
- `bandwidth_trend` 查询单个账号；`trend_type: 1` 固定最近 60 分钟，忽略时间参数。
- `trend_type: 2` 用秒级 Unix `startTime/endTime`，跨度最多 2 天，省略默认最近 1 天。
- 监控异常先结合账号状态、已购带宽与采样时间解释，不自动升级带宽。不要调用这些工具推断产品 11 的实时带宽监控。
